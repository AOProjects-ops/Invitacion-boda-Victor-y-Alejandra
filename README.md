Archivos que debes subir a la raíz del repositorio de GitHub:

- `index.html`  (ya incluye la foto de portada y la foto de las manos)
- `musica.mp3`  (TU canción, con ese nombre exacto)

Luego: Settings → Pages → Branch `main` → carpeta `/ (root)`.

## Qué personalizar (arriba del bloque <script> en index.html, dentro de CONFIG)
- `whatsapp`: tu número con código de país. Ej: `573001234567`
- `mapUrl`: enlace de Google Maps de la iglesia (opcional)
